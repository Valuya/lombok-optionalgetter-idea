# Changelog

## [Unreleased]

## [1.0.2]

### Fixed

- **Find Usages** on an `@OptionalGetter` field now reliably includes the generated `getXxxOptional()`
  accessor's call sites: the getter is *added* to the field's accessors rather than replacing them, so the
  field's direct references and its `@Setter` accessor are still found too.

### Added

- Marketplace release notes / "What's new" are now published for every version (from this changelog).

## [1.0.1]

### Added

- **Find Usages** on an `@OptionalGetter` field now also finds the generated `getXxxOptional()` accessor's
  call sites, not just direct field references.

## [1.0.0]

### Added

- Initial release: **code completion**, **find usages**, and **go-to-declaration** (onto the field) for the
  `getXxxOptional()` accessors generated by `@OptionalGetter` (from the `io.github.valuya:lombok` overlay).
  The calls no longer show as unresolved in the editor.
