# lombok-optionalgetter-idea

IntelliJ IDEA editor support for **`@OptionalGetter`** from the
[`io.github.valuya:lombok`](https://github.com/Valuya/lombok-optionalgetter) overlay.

`@OptionalGetter` generates a `getXxxOptional()` accessor returning `Optional<T>`. IntelliJ's bundled Lombok
plugin only knows Lombok's *built-in* annotations, so those generated methods otherwise show up as
**unresolved** in the editor (red code, no completion, no navigation) even though the real build compiles fine.

This plugin injects the generated accessors into IntelliJ's model, so they behave like any other method:

- **Code completion** on `getXxxOptional()` ✅
- **Find usages** ✅
- **Go to declaration** → lands on the annotated field ✅
- no more "cannot resolve method" ✅

It runs alongside (does not depend on) the bundled Lombok plugin, and does **not** run the annotation
processor — the real accessor is still generated by the overlay at compile time. This only feeds the IDE's
static model, the same way the Lombok plugin does for `@Getter` (via a `PsiAugmentProvider`).

## Install

- **From JetBrains Marketplace:** Settings → Plugins → Marketplace → search "Lombok @OptionalGetter".
- **From disk:** download the plugin `.zip` from [Releases](https://github.com/Valuya/lombok-optionalgetter-idea/releases),
  then Settings → Plugins → ⚙ → *Install Plugin from Disk…*

Restart the IDE when prompted.

## Compatibility

Built against IntelliJ IDEA 2024.2; `since-build 242` with no upper bound, so it loads in current and newer
IntelliJ (Community or Ultimate). Requires the bundled **Java** and (for real behaviour) the **Lombok** plugin.

## How it works

`OptionalGetterAugmentProvider` is a `com.intellij.psi.augment.PsiAugmentProvider`. For each class it scans
fields annotated with `@lombok.OptionalGetter` (or all non-`@Getter` fields when the annotation is on the type),
skips primitives (which `@OptionalGetter` rejects), and injects a synthetic `public Optional<T> getXxxOptional()`
whose navigation target is the field. Results are cached per class and invalidated on PSI changes.

The accessor-name suffix is `Optional` (the overlay's default `lombok.optionalGetter.suffix`).

## Build

```bash
./gradlew buildPlugin      # -> build/distributions/lombok-optionalgetter-idea-<version>.zip
./gradlew verifyPlugin     # plugin-structure verification
./gradlew runIde           # launch a sandbox IDE with the plugin for manual testing
```
