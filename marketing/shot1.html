OptionalGetter for Lombok
Editor support for @OptionalGetter (from io.github.valuya:lombok-optionalgetter-overlay)

You write

public class Customer {

    @OptionalGetter
    private String email;

}
➞

The editor resolves

// generated, now known to the IDE
public Optional<String> getEmailOptional() {
    return Optional.ofNullable(email);
}
